Configurações

Teams

Cada conta abre numa sessão própria e fica logada. Remover apaga o login salvo dela.

Abas de site

Sites que ficam na barra lateral, cada um com login próprio. Marque "navegador" para abrir fora do app (o Google, por exemplo, recusa login dentro dele). Remover apaga o login salvo da aba.

Skills

Como a aba Skills roda o Claude Code. Sem janela, o Claude não consegue pedir aprovação: o nível de permissão decide o que ele pode fazer sozinho.

Skills exibidas

Desmarque as que não quer ver na aba Skills. Elas continuam instaladas no Claude Code.

Contas do Claude Code

Contas usadas na aba Skills. Cada uma tem a própria pasta de configuração e gasta o plano dela. Adicionar abre um terminal para o login; a conta enxerga as mesmas skills da principal.

Agendas Google

Leitura pela API do Google. "Autorizar" abre o consentimento no seu navegador. Enquanto o app do Google estiver em modo teste, só e-mails cadastrados como usuário de teste no Google Cloud conseguem autorizar, e o acesso precisa ser renovado a cada 7 dias.

Agendas Microsoft

Agenda de outra empresa no Microsoft 365 depende de um app registrado no tenant dela ou de um calendário publicado (.ics). Isso continua pelo terminal: veja a skill terras-agenda.
